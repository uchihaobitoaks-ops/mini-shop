# Конфликт в Git

## Где возник
В файле README.md, строка "## Статус".

## Причина
В ветке main было значение "MVP готов", в ветке feature/conflict-demo — "альфа-версия". Обе ветки меняли одну и ту же строку.

## Как исправлен
Через интерфейс GitHub (Resolve conflicts). Маркеры конфликта удалены, оставлен вариант "MVP готов", сделан merge commit.
